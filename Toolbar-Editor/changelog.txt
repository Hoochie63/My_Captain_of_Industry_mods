v2.0.0 | 2026-08-24
Ω—Toolbar Editor—Ω

===============
GETTING STARTED
===============
- Live visual edit mode.
- Work with five focused tabs—Layout, Sections, Buttons, Profiles, and Settings—with footer controls and the Fine Tune tray available throughout the editor.
- Left-click the Toolbar Editor tool shortcut or optional calendar T to open Editor & Settings; right-click either shortcut to toggle Edit Mode immediately.
- Use Ctrl + [ to open or close Editor & Settings and Ctrl + ] toggle edit mode.

==========
AUTO-SHIFT
==========
- Leave Auto-Shift ON for a familiar default-style single-row toolbar while using Ctrl + Shift + Left-drag to reorder buttons or move them between sections.
- Turn Auto-Shift OFF and resize the background at least once before dragging any section into a custom position, switching sections to vertical rails, or building multiple button rows or columns.
- With Auto-Shift on, surrounding sections resize and repositions after button drag & dropping or adding/removing custom sections; with it off, established positions stay fixed and new sections appear near the lower center. The chosen mode is saved with the layout.

=================
PER-SAVE LOADOUTS
=================
- Every save gets its own toolbar loadout, completely independent from the world played before it.
- Capture the active toolbar through Save, Save As, or autosave.
- Layout tab has reset-to-defaults to revert all changes made and start fresh.

=================
OPTIONAL PROFILES
=================
- .toolbar loadouts profiles are optional; they can be used to backup your creations and port them into other saves.
- Toolbar Profiles Store component positions, layers, borders, section names and orientations, button assignments, order, visibility and colors, all scales, custom-section count, Auto-Shift, and independent background-movement settings.
- To use a saved profile in another save, Load a saved profile into the current world, then save the game.

===============
EDIT LAYOUT TAB
===============
- Toggle Toolbar Edit Mode, show or hide highlighted component drag handles, and a collapsible Controls card that displays the shortcuts for live editting controls.
- Ctrl + Left-drag any toolbar component.
- Shift + Left-drag resizes the width of Search, the toolbar background, or the Submenu and item panel.
- Alt + Left-drag resizes the height of Search or the toolbar background.
- Ctrl + Shift + Left-drag a button to reorder it inside its section or move it into another section with orientation-aware insertion and automatic section resizing.
- Ctrl + Shift + Alt + Left-click brings a toolbar section or Search forward, while the same modifiers with Right-click send it backward.
- Move Back Indepdantly affects whether sections move together with the toolbar background or remain in their fixed positions.
- Scale options for the toolbar background & sections,  the Search bar,Submenu and item panel, and resets.
- Reset Search, the Submenu and item panel, the toolbar background and all standard sections, or use reset toolbar + all sections to start over fresh.

==============
FINE TUNE TRAY
==============
- The fine Tune tray gives access to frequently used actions found in in the Editor's tabs.
- Open the Fine Tune tray by clicking the gold footer arrow; its open state is remembered globally.
- Enable Selection Mode during editing, then left-click editable components to make changes to the component selected.
- Identify the selected component directly on the live toolbar and view its component name and type in the tray.
- Nudge in four directions by 1 pixel with Left-click or 10 pixels with Right-click, or enter exact X and Y screen coordinates and apply them.
- Independently scale Search, the Submenu and item panel, and both native green tool-shortcut button containers, with a dedicated per- component Reset.
- Move supported targets backward or forward by one layer, cycle bottom borders, switch yellow sections between horizontal and vertical, and reset the selected component's position, supported scale, layer, and border.

============
SECTIONS TAB
============
- Manage up to twenty active section slots: twelve custom sections, six Toolbar Editor default containers, and two native green tool-shortcut hosts containers.
- Add a new empty section, remove empty sections, identify every active section, and see the live active-section count.
- Select any active section from the dropdown, identify it by name, and rename it.
- Switch the six default and custom sections between a natural horizontal row and a one-column vertical section.
- Cycle bottom border through Off, Concave, and Convex, or choose one style and apply it across all standard sections.
- Inspect section type, exact X/Y position, effective scale, orientation, layer order, button count, and assigned button names—including hidden assignments—from Section Stats.
- Reset a standard section's position, supported scale, layer, and border while preserving its custom name, orientation, and assigned buttons; newly researched menus or newly added mods can automatically restore a removed section if that was it's default home.

===========
BUTTONS TAB
===========
- Browse collapsible groups for every tracked section based on your current layout including empty groups, with section Rename and Identify controls directly above its buttons.
- See every tracked button under its current named section with a name; hidden buttons remain listed and manageable.
- Show or hide tools or menu buttons.
- Use the color picker with 18 preset colors, hexadecimal input, independent RGB sliders, or reset to the original color.
- bulk recolor all buttons in a section, or across all buttons at once.
============
PROFILES TAB
============
- Save the current toolbar under a new profile name or deliberately overwrite an existing .toolbar.
- Load a selected profile with confirmation, rename it, or permanently delete it.
Green and red status text to see successful profile operations and rejected or invalid files.
- Copy the Profiles folder path and past into Explorer or sharing or backup, and use Refresh to rescan .toolbar files added, removed, or renamed outside the game.
- Before leaving Edit Mode, you will be reminded to eve any unsaved changed to the profile. This can be disabled in settings

========
SETTINGS
========
- Choose the Toolbar Editor button icon from eight options: Compact Block Hammer, Original Detailed Hammer, Soft Mallet, Outline Mallet, Inferno T, Inferno Double Hammer T, Burning T, and Industrial Toolbox.
- Disable editor tooltips, or disable the named-profile unsaved-change warning.
- Enable a bottom-edge vertical resize strip to resize thr editor's menu height.
- option to automatically name a section after the first button dropped into it.

======================
EDITOR TITLE & FOOTER BUTTONS
======================
- Pin button.
- Editor menu scale size
- Use the persistent footer on every tab to finish editing, move the background independently, toggle Auto-Shift and highlighted bounds, add or remove sections, and identify all sections.
- When Tweaks++ is detected, open its HUD settings directly from the Toolbar Editor footer and lock or unlock Tweaks++ HUD positions without leaving the editor.
