TOOLBAR TWEAKS
==============

Toolbar Tweaks turns the Captain of Industry toolbar into a complete visual
editor without replacing the menus, buttons, text, or actions that already
exist.

GETTING STARTED
---------------

- Detected third-party top-level menus are collected into a dedicated Mod
  menus section instead of being mixed into the vanilla Buildings section.
- Left-click the gold wrench to open or close Toolbar Tweaks - Editor &
  Settings.
- Right-click the wrench to toggle Edit Mode immediately.
- The optional T button beside the calendar provides the same access if the
  toolbar wrench is moved out of reach.
- Ctrl + [ and Ctrl + ] always remain available as fallback shortcuts.
- If Keybind Framework is installed, Toolbar Tweaks registers its two shortcuts
  in a dedicated Toolbar Tweaks tab. NE: Keybinds is not required.

LAYOUT EDITOR
-------------

Select [Edit layout] to highlight editable toolbar components, then use:

- Ctrl + Left-drag: Move a section anywhere within the screen boundaries.
- Shift + Left-drag: Resize a section horizontally.
- Alt + Left-drag: Resize a section vertically. Dragging below its normal
  height can also shrink its buttons.
- Ctrl + Shift + Left-drag: Drag and drop buttons to reorder them or move them
  between sections.
- Ctrl + Shift + Alt + Left/Right-click: Bring a section or the search panel
  forward, or send it backward.

Additional Layout Editor features:

- Move sections together with the toolbar background, or leave them fixed.
- Scale the complete toolbar from 50% to 200%.
- Scale the Ctrl+F search control independently from 50% to 200%.
- Scale the submenu and item panel independently from 76% to 200%.
- Add custom sections, up to a total of twenty active sections.
- Remove the last empty section without deleting occupied sections.
- Show or hide individual toolbar buttons from a collapsible list.
- Reset individual components or restore the complete Toolbar Tweaks layout.
- Screen-edge limits and cancelled invalid drops keep components and buttons
  recoverable.

CUSTOMIZE SECTIONS
------------------

- Select any active section from the compact dropdown.
- Rename native sections, the Mod menus section, or custom sections to keep
  complex layouts understandable.
- Custom section names persist with the live layout and are included in
  .toolbar profile files.
- Reset Section restores only that section's position, size, layer, and border;
  its custom name and assigned buttons are preserved.
- Cycle the selected section's bottom border through Off, Concave, and Convex.

SETTINGS AND TOOLBAR PROFILES
-----------------------------

- Save the current arrangement as a reusable .toolbar profile.
- Select, load, overwrite, rename, or permanently delete saved profiles.
- The selected profile and currently active toolbar are shown separately.
- The Status panel reports successful actions and errors.
- Copy the profiles folder path for File Explorer or profile sharing.
- Use Refresh after adding, removing, or renaming .toolbar files outside the
  game.
- Show or hide the optional calendar T button without affecting the toolbar
  wrench or Ctrl + ].

LOCALIZATION
------------

Toolbar Tweaks includes English plus 18 additional languages:

Catalan, Czech, German, Spanish, Estonian, French, Hungarian, Italian,
Japanese, Korean, Norwegian, Dutch, Polish, Portuguese, Russian, Swedish,
Ukrainian, and Chinese.

COMPATIBILITY
-------------

Toolbar Tweaks reuses each original live toolbar button. Menu names, category
IDs, icons, tooltips, actions, research unlocks, selected states, visibility
rules, and translations remain owned by Captain of Industry and the mod that
registered them.

The mod adds no save-game data, requires neither NE: Keybinds nor Keybind
Framework, and can be added to or removed from an existing save.

KNOWN BUGS OR LIMITATIONS
-------------------------

- Complex layouts involving the top of the screen may require you to load the
  profile after loading your game. — (hopefully fixed)
- Optional calendar T button only works until you exit the game. (will fix
  soon)
- Submenu & Item panel may not always behave perfectly when rescaled or too
  close to screen's edge, try reloading the profile, or reset the Submenu & Item
  panel in layout editor.
