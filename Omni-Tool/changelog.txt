SCRAP & REPLACE REWORK
======================
- Uses a custom queue system that sends vehicles marked for scrap/replace to multiple nearby vehicle depots at once using a lane system. Has the best results when your vehicle depots are spread out. This prevents the "All-to-one-depot" bottleneck that could occur by scrapping/replacing many vehicles at once with previous version; Tests shown significant speed-up in replacing 100+ vehicles at once.
- Micro-HUD displays the live queue grouped by vehicle and operation, including waiting, active, canceling, and available-depot counts with options to remove undesired vehicles from the queue.
(Will improve selection filtering & details further in next version)

- Adjusted click-through guard so cycle tool keybind isn't blocked when your mouse is over the micro-HUD.

v0.7.0 | 2026-09-07

[NEW TOOLS & ADDITIONS]

- Added Downgrade Buildings and Cancel Deconstruction swipe tools.
- Added Building Settings Brush for selectively mass-applying building priority, truck import/export policies, and empty/full storage alerts. Every section is independently opt-in, and unsupported properties are skipped safely.
- Added Terrain Eraser for cutting precise ravines and canals down to an absolute target height. Its normal -10 to 0 range favors detailed work, with an opt-in -50 to +50 range for extreme edits. Expanded range always starts off when a new profile is cloned.
- Added Box Selection, Round Brush & undo function for Tree Painter, Terrain Sculpting, and Terrain Eraser. Undo can remember 1-10 action history. Terrain settling and buildings already destroyed by collapse remain permanent, so terraform while paused for the safest undo results.
- Expanded Scrap Vehicles to include Replace vehicle actions; Compatibility and depot failures remain handled by the native command.
- Renamed Fill Terrain to Mine / Dump Designations. Added up to five remembered product favorites to its Micro HUD; left-click selects one and right-click removes it.
- Added a Cheat++-conditional Keep Full / Empty tool for mass-applying Keep Full, Keep Empty, or Normal storage states.

[OMNI-BELT PROFILES]

- Rebuilt Omni-Belt profiles as a named, reorderable, auto-saving system. Rename profiles directly in the tray, choose which participate in shortcut cycling, and reorder the tray to control that cycle order.
- Added default Vehicle Tools and Building Tools profiles for new installations. Sandbox-eligible installations also receive a prepared Terraforming profile that remains outside profile cycling and dormant until sandbox tools are enabled in settings.
- Added per-profile Vehicle, Logistics, Buildings, and Sandbox visibility controls, plus Hide Unequipped for the editor. Hidden categories and tools retain their saved colors, settings, states, and relative order.
- Added dual-category tags for shared tools: Unity Quick Repair belongs to Vehicles and Buildings, while Storage Magic Wand and Cheat++ Keep Full / Empty belong to Sandbox and Buildings. Either visible category keeps a shared card available.
- Made the Profile Switcher and Settings Shortcut full Omni-Belt cards. Both can be enabled, disabled, recolored, and reordered alongside ordinary tools.
- Added active-profile Reset Tool Order, Reset Colors, and Enable All Available Tools actions. Color reset returns ordinary tools to white and both Omni-Belt utility cards to yellow. A separate factory restore rebuilds the installed profile set behind two confirmations.

[SETTINGS, SAFETY & UI POLISH]

- Opening Settings cancels every active Omni-Tool action and drag while leaving the Omni-Belt visible as a dimmed, non-activating preview to prevent accidental tool use while configuring.
- Split the editor into Tools, Per-Profile Omni-Belt Settings, and global Settings tabs.
- Made Enable Sandbox Tools a conditional global master switch. It and Creative Undo appear only when Cheat++ or the disabled-by-default Mod Config option grants sandbox eligibility.
- Made the settings window fully resizable on both axes, constrained it to a practical 500-1000 px width, and kept reorder controls outside the scrolling card list. Building Settings logistics policies use compact single-line controls so Import and Export remain stable across translations.
- Restricted tool-card and profile reordering to visible drag handles, which update immediately with Reorder mode. 
- Converted all 21 language catalogs to explicit English-key-to-translated-value entries and added the complete 0.7 interface vocabulary.
