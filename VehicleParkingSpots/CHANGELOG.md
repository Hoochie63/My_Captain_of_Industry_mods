# Changelog

All notable changes to Vehicle Parking Spots are documented here.

## 0.9.0 — 2026-09-01

- Added five distinct 256 × 256 parking-type toolbar icons embedded in the mod assembly.
- Added optional vanilla decal parking-bay visualization for every parking size.
- Added parking state and access indication to the two-light parking beacon.
- Added vehicle assignment highlighting and parking information to inspectors.
- Added maintenance consumption reduction while a vehicle is parked.
- Improved parking centering, alignment tolerance, category filtering, reservation handling, and cleanup.
- Added complete compatibility, copyright, package, and assembly metadata.
