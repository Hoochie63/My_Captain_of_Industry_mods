Vehicle Parking Spots 0.9.0
Compatible and verified with Captain of Industry 0.8.6c.

INSTALLATION
Copy the complete VehicleParkingSpots directory into:
%APPDATA%\Captain of Industry\Mods\

The final path must contain:
%APPDATA%\Captain of Industry\Mods\VehicleParkingSpots\manifest.json
%APPDATA%\Captain of Industry\Mods\VehicleParkingSpots\VehicleParkingSpots.dll

Enable modding in the game settings, enable Vehicle Parking Spots for the game,
and restart the game after replacing the DLL.

IMPORTANT SAVE INFORMATION
The mod can be added to an existing save. It cannot be safely removed from a
save that contains parking entities. Back up saves before updating or removing
mods.

FEATURES
- Five parking sizes for light vehicles, trucks, large trucks, excavators, and
  heavy machinery.
- Public, vehicle-category, and specific-vehicle access modes.
- Parking state beacon, inspector status, vehicle highlighting, optional vanilla
  horizontal marking, and reduced maintenance consumption while parked.
