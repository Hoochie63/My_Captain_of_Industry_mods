v1.0.0 | 2026-08-10
* Added: Right-click an arrow to send a task straight to the top or the bottom of the list
* Added: Section headers now show how many tasks they hold
* Changed: All eleven languages updated

v0.3.0 | 2026-08-09
* Added: Link a task to a building. Select a building, click the link icon on the task, and the task remembers it
* Added: Click the gold pin on a linked task to move the camera there and open the building panel
* Added: Click the link icon again to remove the link
* Changed: Row buttons now appear on hover, so the list stays readable at rest
* Note: A link to a demolished building clears itself
