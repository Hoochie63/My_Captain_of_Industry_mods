Smart Flare Mod – Übersetzungen / Translations

DEUTSCH

Jede JSON-Datei enthält eine Sprache und ist als UTF-8 gespeichert.
Die Dateinamen entsprechen den Spielsprachen, z. B. de.json, en.json,
pt_BR.json, zh_Hans.json und zh_Hant.json.

- Nur die Texte rechts bearbeiten, nicht die Bezeichnungen links.
- Platzhalter wie {0} und {1} sowie vorhandene Formatierungen beibehalten.
- Das Spiel nach Änderungen neu starten. Ein Neubau der DLL ist nicht nötig.
- Fehlende oder fehlerhafte Einträge verwenden vorhandene Ersatztexte.
- Die bisherigen Übersetzungen wurden übernommen. Einige neuere Texte sind
  bisher nur auf Deutsch, Englisch und Russisch übersetzt. In den anderen
  Sprachdateien stehen diese Texte auf Englisch und können ergänzt werden.
- Produktnamen und die Namen der ursprünglichen Gebäude übersetzt das Spiel.
- Changelog und Installationsanleitung sind separate Dokumente, keine UI-Texte.

Eigene Korrekturen vor Updates schützen

Lege eigene Sprachdateien in diesem Ordner ab:
%APPDATA%\Captain of Industry\ModConfigs\SmartFlareMod\translations

Die Dateien dürfen nur die Einträge enthalten, die du ändern möchtest.
Sie werden nach den mitgelieferten Übersetzungen geladen. Dateien im
Mod-Ordner selbst können bei einem Update überschrieben werden.

ENGLISH

Each UTF-8 JSON file contains one language. Filenames match the game's language
identifiers, such as de.json, en.json, pt_BR.json, zh_Hans.json and zh_Hant.json.

- Edit text values on the right, not keys on the left.
- Keep placeholders such as {0} and {1}, and any existing text formatting.
- Restart the game after editing. No DLL rebuild is required.
- Missing or invalid entries retain fallback text.
- Existing translations are preserved. Some newer texts are translated only
  into German, English and Russian; other files include English text for
  these entries so community translators can complete them.
- Original building and product names are translated by the game.
- The changelog and installation guide are separate documents, not UI text.

Update-safe personal corrections

Place personal language files in:
%APPDATA%\Captain of Industry\ModConfigs\SmartFlareMod\translations

These files may contain only the keys you want to change. They load after
the bundled files. Files inside the mod folder may be replaced by updates.
