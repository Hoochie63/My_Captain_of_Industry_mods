# Changelog

## 1.0.0

- Added automatic detection of compatible Pipe, Loose, and Flat output groups.
- Added per-machine output-port routing and persistence.
- Added product names and source-port assignments to inspector controls.
- Added automatic hiding of redundant routing groups for assigned recipes.
- Added live inspector refresh when recipe assignments change.
- Added internal-output-buffer safety checks before changing or resetting routing.
- Added routing support for existing and newly constructed machines.
- Added cleanup of saved routing data after full machine deconstruction.
- Preserved routing through machine upgrades.
- Added legacy X/Y swap migration.

## 1.0.1

- Added localized UI text.
- Added a collapsible Output Routing section.
- Routing controls now stay hidden until expanded.
- Added live UI refresh when the selected language changes.
