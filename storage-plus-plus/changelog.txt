v1.1.5 | 2026-07-22
* Saved settings now live in a shared "Mori++ Saved settings" folder outside the mod folder, so a manual delete or a mod manager wiping the folder no longer loses them. Because of this move, all your current settings reset to default one time — set everything up again and from then on they're kept safe in that folder.
* The Mori++ HUD buttons are now one single "O" Overlord button — click it to open one window with a tab for each installed mod's settings, instead of a separate button per mod.
* Overlord now has its own keybind (Alt+W by default) to open or close it. Can be changed in Keybind Framework if installed.
v1.1.4 | 2026-07-15
* Now supports game version 0.8.6 (experimental), and remains compatible back to 0.8.4.
* Custom Capacity overrides now stay put when you move or upgrade a storage building — before, moving or upgrading a storage quietly reset its capacity back to the default. (thanks SlyPulsar for the report)
* Storage alert dropdowns (bell icon on any storage building) now also include 5%, 10% and 15% options for Notify if Empty — an early warning when a storage is running low, not just 25% steps. (thanks michael0981 for the suggestion)

v1.1.3 | 2026-07-01
* All translations have been updated, thanks to Hoochie for the updated Russian translation.
* Storage alert dropdowns (bell icon on any storage building) now include 80% and 90% options for Notify if Empty/Full, not just 25% steps. (thanks michael0981 for the suggestion)
* The Throughput tab now includes cargo ship modules, grouped in their own section — set their transfer rate like other storages. (thanks SlyPulsar for the suggestion)
* You can now override Ore Sorting Plant storage capacity (unsorted/sorted) — this pauses Boost++'s capacity boost on it until rested to default on storage++ for ore sorters. (thanks Hoochie for the suggestion)

v1.1.2 | 2026-06-26
* New per-building "Allow all products" checkbox in each storage's window — lets that storage hold any item of its type (loose, fluid or unit), ignoring the usual restrictions.

v1.1.1 | 2026-06-21
* Fixed storages sometimes loading the wrong capacity from a different save — a value you set on one save could show up on a building in another save, or a building you never changed could suddenly change (often setting off a low-storage warning). 
   Capacity and throughput settings are now kept separately per save, so they can no longer leak between saves. (thanks Arbaaz_Mir for the report)
* All Storage++ settings now save as plain files in the mod's Saved Settings folder — per-save settings go in a folder named after your save, global ones stay in the main folder — so they're easy to find and back up.
* Cargo ship modules (Unit, Loose and Fluid) can now have their storage capacity changed — set each size from the new Storage Ship tab.
* The storage window is split into Storage Ground, Storage Trains and Storage Ship tabs, each grouping its storage type, and is now a little wider.

v1.0.9 | 2026-06-10
