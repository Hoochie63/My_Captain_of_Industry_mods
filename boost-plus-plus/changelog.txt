v1.2.0 | 2026-07-29
* Now supports game version 0.8.6b.

v1.1.9 | 2026-07-24
* Saved settings now live in a shared "Mori++ Saved settings" folder outside the mod folder, so a manual delete or a mod manager wiping the folder no longer loses them. Because of this move, all your current settings reset to default one time — set everything up again and from then on they're kept safe in that folder.
* The Mori++ HUD buttons are now one single "O" Overlord button — click it to open one window with a tab for each installed mod's settings, instead of a separate button per mod.
* Overlord now has its own keybind (Alt+W by default) to open or close it. Can be changed in Keybind Framework if installed.
* Balancers can now be boosted just like connectors, lifts and sorters — from the balancer window, groups, and mass select.
* Click to select and Drag to select (Mass Select tab) now switch your mouse cursor to a select-area icon while active, so it's clear the tool is on.
* Fixed the copy tool not carrying over an under-100% boost when copy-pasting buildings — it reset to 100% instead. (thanks Denis for the report)
* Fixed Ore Sorting Plant boost losing its sorting speed bonus when Storage++ overrides its capacity — speed boost works again. (thanks Hyperion2950 for the report)
* Fixed the Groups tab collapsing into a narrow strip with squashed, wrapped buttons.

v1.1.5 | 2026-06-24

* Added a Rename button to each row in the Mass Select tab.
* Added a Sort button to the Mass Select tab — order by boost %, name (A-Ö) or type, remembered between sessions.

v1.1.4 | 2026-06-21
* You can now add Connectors, Lifts and Sorters to groups with "Click to select" and "Drag to select" — previously only buildings, belts and pipes could be grouped.
* New Connectors, Lifts and Sorters buttons in the group "Apply to" row, so Apply and Reset can target those types like buildings, belts and pipes.
* New Sort button for group members — order by speed, name (A-Ö) or type, and your choice is now remembered between sessions.
* Renaming and editing in the manager now updates instantly instead of taking several seconds or needing the window closed and reopened.
* The Boost slider now works on connectors, lifts and sorters too — open one and drag the slider to raise that building's throughput, like belts and machines. (Thanks warrenc for report on connectors chokepoint!)
* Speed-boosted belts now hold more items too — scales with the boost, up to double at max. Helps long belt lines feed more machines at the cost of much more power use as balance. 
   From 0-49% it is regular boost way and after that the curve for inventory boost kicks in. (thanks notmuted for great suggestion and helping test the version)
