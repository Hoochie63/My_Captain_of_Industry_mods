## ✅ РАБОТАЮЩИЕ ТЕГИ

|         Тег         | Закрытие тега  |            Описание             |                      Пример из теста                       |
|:-------------------:|:--------------:|:-------------------------------:|:----------------------------------------------------------:|
| `<align="center">`  |   `</align>`   |     Выравнивание по центру      |         <div align="center">Текст по центру</div>          |
|  `<align="right">`  |   `</align>`   |  Выравнивание по правому краю   |           <div align="right">Текст справа</div>            |
|     `<allcaps>`     |  `</allcaps>`  |          Все заглавные          |                ЭТОТ ТЕКСТ СТАНЕТ ЗАГЛАВНЫМИ                |
|    `<alpha=#88>`    |   (не закр.)   |      Полупрозрачный текст       |   <span style="opacity:0.5">Полупрозрачный текст </span>   |
|      `<b><i>`       |   `</i></b>`   |          Жирный курсив          |                    ***жирный курсив***                     |
|        `<b>`        |     `</b>`     |          Жирный текст           |                         **жирный**                         |
|       `<bc>`        |    `</bc>`     | Выделение текста жёлтым в целях |        Выделяет текст жёлтым цветом в целях игрока.        |
|       `<br>`        |   (не закр.)   |  Принудительный перенос строки  |                    Строка 1<br>Строка 2                    |
|      `\u00AD`       |   (не закр.)   |      Мягкий перенос строки      |             Переносит только если не влезает.              |
|      `\u00A0`       |   (не закр.)   |       Неразрывный пробел        |         Склеивает слова, чтобы они не разрывались          |
|        `\t`         |   (не закр.)   |            Табуляция            |               Редко, но бывает для отступов.               |
|  `<color=#FF0000>`  |   `</color>`   |          Красный цвет           |        <span style="color:red">Красный цвет</span>         |
|  `<color=#FFCE56>`  |   `</color>`   |           Жёлтый цвет           |       <span style="color:yellow">Жёлтый цвет</span>        |
| `<color=#00FF00FF>` |   `</color>`   |   Зелёный полупрозрачный цвет   |   <span style="color:rgba(0,255,0,0.5)">Зелёный </span>    |
|  `<cspace=-0.1em>`  |  `</cspace>`   |        Уплотненный текст        |              уплотненный (визуально плотнее)               |
|  `<cspace=0.5em>`   |  `</cspace>`   |        Разреженный текст        |                   Р а з р е ж е н н ы й                    |
|        `<i>`        |     `</i>`     |             Курсив              |                          *курсив*                          |
|   `<indent=10%>`    |  `</indent>`   |      Отступ первой строки       |        Абзац с отступом первой строки в 10% ширины         |
| `<line-indent=2em>` |  `(не закр.)   |   Отступ каждой новой строки    |               Каждая новая строка с отступом               |
|    `<lowercase>`    | `</lowercase>` |          Все строчные           |                этот текст станет строчными                 |
|    `<margin=50>`    |  `</margin>`   |         Отступ по краям         |          Текст с отступом по краям на 50 пикселей          |
| `<mark=#FFFF0088>`  |   `</mark>`    |        Выделение текста         |             Выделенный текст (желтая заливка)              |
|      `<nobr>`       |   `</nobr>`    |     Запрет переноса строки      |                Длинный текст без переносов                 |
|     `<noparse>`     |  `</noparse>`  |    Отключение парсинга тегов    | `<b>Этот текст не будет жирным</b>` (теги видны как текст) |
|     `<pos=50%>`     |   (не закр.)   |        Позиция на строке        |             Текст со смещением к центру строки             |
|    `<rotate=15>`    |  `</rotate>`   |         Поворот текста          |              Повернутый на 15 градусов влево               |
|        `<s>`        |     `</s>`     |        Зачеркнутый текст        |                     <s>зачеркнутый</s>                     |
|    `<size=50%>`     |   `</size>`    |        Уменьшенный шрифт        |        <span style="font-size:0.5em">мелкий</span>         |
|    `<size=200%>`    |   `</size>`    |        Увеличенный шрифт        |     <span style="font-size:2em">Огромный шрифт</span>      |
|    `<space=5em>`    |   (не закр.)   |      Горизонтальный пробел      |                     большой     пробел                     |
|       `<sub>`       |    `</sub>`    |          Нижний индекс          |                  нижний<sub>индекс</sub>                   |
|       `<sup>`       |    `</sup>`    |         Верхний индекс          |                  верхний<sup>индекс</sup>                  |
|        `<u>`        |     `</u>`     |       Подчеркнутый текст        |                    <u>Подчеркнутый</u>                     |
|    `<uppercase>`    | `</uppercase>` |  Все заглавные (альтернатива)   |                        И ЭТОТ ТОЖЕ                         |
| `<voffset=-0.5em>`  |  `</voffset>`  |         Опущенный текст         |                 опущенный (ниже baseline)                  |
|  `<voffset=0.5em>`  |  `</voffset>`  |        Приподнятый текст        |                Приподнятый (выше baseline)                 |
|    `<width=200>`    |   `</width>`   |    Ограничение ширины текста    |        Текст обрезается по ширине 200px (пикселей)         |
