# Тестирование Rich Text тегов TextMesh Pro

## 📋 Легенда
- ✅ **Работает** — тег применил эффект к тексту
- ❌ **Не работает** — тег отобразился как обычный текст
- ❓ **Требует проверки** — невозможно однозначно определить по скрину

## ✅ РАБОТАЮЩИЕ ТЕГИ

| Тег                 | Описание                      | Пример из теста                                                                       |
|---------------------|-------------------------------|---------------------------------------------------------------------------------------|
| `<b>`               | Жирный текст                  | **жирный**                                                                            |
| `<i>`               | Курсив                        | *курсив*                                                                              |
| `<b><i>`            | Жирный курсив                 | ***жирный курсив***                                                                   |
| `<color=#FF0000>`   | Красный цвет                  | <span style="color:red">Красный цвет</span>                                           |
| `<color=#00FF00FF>` | Зеленый с прозрачностью       | <span style="color:rgba(0,255,0,0.5)">зеленый с прозрачностью</span>                  |
| `<alpha=#88>`       | Полупрозрачный текст          | <span style="opacity:0.5">Полупрозрачный текст - выполняется без закрытия тега</span> |
| `<size=200%>`       | Увеличенный шрифт             | <span style="font-size:2em">Огромный шрифт</span>                                     |
| `<size=50%>`        | Уменьшенный шрифт             | <span style="font-size:0.5em">мелкий</span>                                           |
| `<u>`               | Подчеркнутый текст            | <u>Подчеркнутый</u>                                                                   |
| `<s>`               | Зачеркнутый текст             | <s>зачеркнутый</s>                                                                    |
| `<sup>`             | Верхний индекс                | верхний<sup>индекс</sup>                                                              |
| `<sub>`             | Нижний индекс                 | нижний<sub>индекс</sub>                                                               |
| `<allcaps>`         | Все заглавные                 | ЭТОТ ТЕКСТ СТАНЕТ ЗАГЛАВНЫМИ                                                          |
| `<uppercase>`       | Все заглавные (альтернатива)  | И ЭТОТ ТОЖЕ                                                                           |
| `<lowercase>`       | Все строчные                  | этот текст станет строчными                                                           |
| `<space=5em>`       | Горизонтальный пробел         | большой пробел - выполняется без закрытия тега                                        |
| `<margin=50>`       | Отступ по краям               | Текст с отступом по краям на 50 пикселей                                              |
| `<indent=10%>`      | Отступ первой строки          | Абзац с отступом первой строки в 10% ширины                                           |
| `<line-indent=2em>` | Отступ каждой новой строки    | Каждая новая строка с отступом                                                        |
| `<cspace=0.5em>`    | Разреженный текст             | Р а з р е ж е н н ы й                                                                 |
| `<cspace=-0.1em>`   | Уплотненный текст             | уплотненный (визуально плотнее)                                                       |
| `<pos=50%>`         | Позиция на строке             | Текст со смещением к центру строки                                                    |
| `<voffset=0.5em>`   | Приподнятый текст             | Приподнятый (выше baseline)                                                           |
| `<voffset=-0.5em>`  | Опущенный текст               | опущенный (ниже baseline)                                                             |
| `<rotate=15>`       | Поворот текста                | Повернутый на 15 градусов влево                                                       |
| `<mark=#FFFF0088>`  | Выделение текста              | Выделенный текст (желтая заливка)                                                     |
| `<align="center">`  | Выравнивание по центру        | <div align="center">Текст по центру</div>                                             |
| `<align="right">`   | Выравнивание по правому краю  | <div align="right">Текст справа</div>                                                 |
| `<width=200>`       | Ограничение ширины текста     | Текст обрезается по ширине 200px (пикселей)                                           |
| `<noparse>`         | Отключение парсинга тегов     | `<b>Этот текст не будет жирным</b>` (теги видны как текст)                            |
| `<br>`              | Принудительный перенос строки | Строка 1<br>Строка 2                                                                  |
| `<nobr>`            | Запрет переноса строки        | Длинный текст без переносов                                                           |
