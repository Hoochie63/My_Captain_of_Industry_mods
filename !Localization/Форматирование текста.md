## ✅ РАБОТАЮЩИЕ ТЕГИ

|         Тег         |            Применение             |           Описание            |                      Пример из теста                       |
|:-------------------:|:---------------------------------:|:-----------------------------:|:----------------------------------------------------------:|
| `<align="center">`  |   `<align="center">...</align>`   |    Выравнивание по центру     |         <div align="center">Текст по центру</div>          |
|  `<align="right">`  |   `<align="right">...</align>`    | Выравнивание по правому краю  |           <div align="right">Текст справа</div>            |
|     `<allcaps>`     |     `<allcaps>...</allcaps>`      |         Все заглавные         |                ЭТОТ ТЕКСТ СТАНЕТ ЗАГЛАВНЫМИ                |
|    `<alpha=#88>`    |    `<alpha=#88>...` (не закр.)    |     Полупрозрачный текст      |   <span style="opacity:0.5">Полупрозрачный текст </span>   |
|      `<b><i>`       |        `<b><i>...</i></b>`        |         Жирный курсив         |                    ***жирный курсив***                     |
|        `<b>`        |           `<b>...</b>`            |         Жирный текст          |                         **жирный**                         |
|       `<br>`        |         `<br>` (не закр.)         | Принудительный перенос строки |                    Строка 1<br>Строка 2                    |
|      `\u00AD`       |            (не закр.)             |     Мягкий перенос строки     |             Переносит только если не влезает.              |
|      `\u00A0`       |            (не закр.)             |      Неразрывный пробел       |         Склеивает слова, чтобы они не разрывались          |
|        `\t`         |            (не закр.)             |           Табуляция           |               Редко, но бывает для отступов.               |
|  `<color=#FF0000>`  |   `<color=#FF0000>...</color>`    |         Красный цвет          |        <span style="color:red">Красный цвет</span>         |
| `<color=#00FF00FF>` |  `<color=#00FF00FF>...</color>`   |         Зеленый цвет          |   <span style="color:rgba(0,255,0,0.5)">Зелёный </span>    |
|  `<cspace=-0.1em>`  |   `<cspace=-0.1em>...</cspace>`   |       Уплотненный текст       |              уплотненный (визуально плотнее)               |
|  `<cspace=0.5em>`   |   `<cspace=0.5em>...</cspace>`    |       Разреженный текст       |                   Р а з р е ж е н н ы й                    |
|        `<i>`        |           `<i>...</i>`            |            Курсив             |                          *курсив*                          |
|   `<indent=10%>`    |    `<indent=10%>...</indent>`     |     Отступ первой строки      |        Абзац с отступом первой строки в 10% ширины         |
| `<line-indent=2em>` | `<line-indent=2em>...` (не закр.) |  Отступ каждой новой строки   |               Каждая новая строка с отступом               |
|    `<lowercase>`    |   `<lowercase>...</lowercase>`    |         Все строчные          |                этот текст станет строчными                 |
|    `<margin=50>`    |     `<margin=50>...</margin>`     |        Отступ по краям        |          Текст с отступом по краям на 50 пикселей          |
| `<mark=#FFFF0088>`  |   `<mark=#FFFF0088>...</mark>`    |       Выделение текста        |             Выделенный текст (желтая заливка)              |
|      `<nobr>`       |        `<nobr>...</nobr>`         |    Запрет переноса строки     |                Длинный текст без переносов                 |
|     `<noparse>`     |     `<noparse>...</noparse>`      |   Отключение парсинга тегов   | `<b>Этот текст не будет жирным</b>` (теги видны как текст) |
|     `<pos=50%>`     |      `<pos=50%>` (не закр.)       |       Позиция на строке       |             Текст со смещением к центру строки             |
|    `<rotate=15>`    |     `<rotate=15>...</rotate>`     |        Поворот текста         |              Повернутый на 15 градусов влево               |
|        `<s>`        |           `<s>...</s>`            |       Зачеркнутый текст       |                     <s>зачеркнутый</s>                     |
|    `<size=50%>`     |      `<size=50%>...</size>`       |       Уменьшенный шрифт       |        <span style="font-size:0.5em">мелкий</span>         |
|    `<size=200%>`    |      `<size=200%>...</size>`      |       Увеличенный шрифт       |     <span style="font-size:2em">Огромный шрифт</span>      |
|    `<space=5em>`    |     `<space=5em>` (не закр.)      |     Горизонтальный пробел     |                     большой     пробел                     |
|       `<sub>`       |         `<sub>...</sub>`          |         Нижний индекс         |                  нижний<sub>индекс</sub>                   |
|       `<sup>`       |         `<sup>...</sup>`          |        Верхний индекс         |                  верхний<sup>индекс</sup>                  |
|        `<u>`        |           `<u>...</u>`            |      Подчеркнутый текст       |                    <u>Подчеркнутый</u>                     |
|    `<uppercase>`    |   `<uppercase>...</uppercase>`    | Все заглавные (альтернатива)  |                        И ЭТОТ ТОЖЕ                         |
| `<voffset=-0.5em>`  |  `<voffset=-0.5em>...</voffset>`  |        Опущенный текст        |                 опущенный (ниже baseline)                  |
|  `<voffset=0.5em>`  |  `<voffset=0.5em>...</voffset>`   |       Приподнятый текст       |                Приподнятый (выше baseline)                 |
|    `<width=200>`    |     `<width=200>...</width>`      |   Ограничение ширины текста   |        Текст обрезается по ширине 200px (пикселей)         |

| (\u2605) |   ★   |        Звезда         |
| (\u221E) |   ∞    |     Бесконечность     |
| (\u00A9) |   ©    |       Копирайт        |
| (\u2122) |   ™    |    Торговая марка     |
| (\u00B0) |   °    |        Градус         |
| (\u00B1) |   ±    |      Плюс-минус       |
